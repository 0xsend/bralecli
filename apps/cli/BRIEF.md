# Agent onboarding quality

Law for agent onboarding, in present tense. Human-confirmed decisions and
boundaries change only with human confirmation; working progress lives outside
this brief.

## Bar

A newly configured Claude Code or Codex agent can discover and operate the
installed CLI from concise instructions grounded in its actual behavior.

## Dimensions and floors

- Discovery and clarity: mirror the README's command-first install style; a
  fresh participant completes setup, schema discovery, pagination planning, and
  transfer recovery planning with no blocking incorrect instructions.
- Portability: isolated source tests and standalone smoke install the exact
  canonical skill without credentials, checkout files, or a runtime on PATH.
- Preservation: installer tests prove repeated installation is unchanged,
  conflicting edits fail before writes, and unrelated instructions survive.
- Observability: successful output names paths and statuses; errors name the
  failed destination or invalid option and leave the process nonzero.

## Oracle

Vitest and the standalone smoke check objective filesystem and CLI behavior.
A fresh participant receives README, the installed skill, a compiled executable,
and isolated temporary directories. The participant follows setup and discovery,
plans a complete transfer listing, and handles an uncertain transfer outcome.
No live API calls are permitted. The budget is four tasks or ten minutes, with
at most two repair rounds. Incorrect command guidance, missing discovery, unsafe
retry advice, or overwritten instructions block; editorial preferences do not.

## Never

Never expose credential values or imply setup authorizes funds movement.
Never present help/schema as a dry run or API acceptance as settled funds.
Never claim a harness or live workflow passed when it was not run.

## Decisions

Provisional, 2026-09-08: use one self-contained shared skill and link Claude's
repository copy to it. Install curated guidance separately from optional
generated API references so the essential operational constraints stay concise.

## Boundary

Publication and live Brale writes require authorization for that outcome. This
verification uses temporary files and synthetic responses only.
